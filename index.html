Diagramas de Dijkstra y Euclides

¿Qué hace esta página?

Este sitio reúne dos componentes educativos: un visualizador interactivo para calcular rutas más cortas con Dijkstra en grafos ponderados y un módulo para estudiar el algoritmo de Euclides que obtiene el máximo común divisor (MCD). Ambos permiten comprender conceptos clave de algoritmos, estructuras de datos y análisis de complejidad.

Temas esenciales que verás

  • Grafos y pesos: nodos, aristas, pesos no negativos, densidad y conectividad.
  • Caminos mínimos: distancias, predecesores y reconstrucción de rutas.
  • Complejidad: Dijkstra O(E log V) con cola de prioridad; O(V²) en implementación simple.
  • Restricciones: Dijkstra requiere pesos no negativos; para negativos se emplea Bellman–Ford.
  • Euclides (MCD): reemplazos sucesivos (a, b) → (b, a mod b); complejidad O(log min(a,b)).

Aplicaciones prácticas

  • Navegación y redes: cálculo de rutas eficientes, ruteo de paquetes, costos mínimos.
  • Planificación: logística, mapas, juegos con mapas o grafos de estados.
  • Criptografía & números: MCD para simplificar fracciones y generar claves (RSA).
  • Exportación y pruebas: guardar grafos y rutas como JSON, exportar imágenes.

Algoritmo de Dijkstra (rutas más cortas)

Encuentra el costo mínimo desde un origen hacia los demás nodos en un grafo con pesos no negativos. Mantiene una distancia mínima conocida para cada nodo y expande el no visitado con menor distancia.

  • Entrada: grafo ponderado y nodo inicial.
  • Salida: distancias mínimas y predecesores para reconstruir rutas.
  • Usos: navegación, redes, planificación de rutas.

Algoritmo de Euclides (máximo común divisor)

Calcula el MCD de dos enteros mediante divisiones sucesivas: se repite (a, b) → (b, a mod b) hasta que el residuo sea cero; el último divisor no nulo es el MCD.

  • Entrada: dos enteros no negativos a, b.
  • Salida: MCD(a, b).
  • Usos: simplificación de fracciones, criptografía, teoría de números.
